# Email signature icons

Icons used in the Gmail signature (phone, email, LinkedIn, web), rendered as 52 × 52 px PNGs in #1a5fa8.

Source: [Material Design Icons](https://pictogrammers.com/library/mdi/) by Pictogrammers (`@mdi/svg` 7.4.47), Apache License 2.0.

Do not rename or delete these files: the signature loads them from https://ch1nmay117.github.io/assets/email/.
